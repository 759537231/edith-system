# 分镜设计方法

## 一、镜头语言

### 景别
| 景别 | 画面范围 | 作用 | 适用 |
|------|----------|------|------|
| 远景 | 环境全貌 | 交代环境、氛围 | 开场、转场 |
| 全景 | 人物全身+环境 | 展示人物与环境关系 | 交代场景 |
| 中景 | 膝盖以上 | 展示动作、交流 | 对话、动作 |
| 近景 | 胸部以上 | 展示表情、情绪 | 情感表达 |
| 特写 | 脸部/细节 | 强调细节、情绪 | 关键时刻、产品 |

### 景别运用原则
- **远景**：建立场景，给观众时间适应
- **中景**：叙事主力，展示动作和关系
- **特写**：强调重点，制造冲击力
- **变化**：景别要有变化，避免单调

## 二、画面切割

### 轴线规则
```
      人物A ←————→ 人物B
           ↑
         镜头
         
镜头只能在轴线一侧拍摄
跨越轴线 = 跳轴（会让观众困惑）
```

### 正反打
```
镜头1：A的过肩看B
镜头2：B的过肩看A
交替使用，展示对话
```

### 过肩镜头
- 从一个人物肩膀后方拍向另一人
- 建立空间关系
- 增加对话的代入感

## 三、分镜表格式

### 标准分镜表
| 编号 | 景别 | 画面描述 | 运镜 | 时长 | 音频 | 备注 |
|------|------|----------|------|------|------|------|
| 1 | 远景 | 城市天际线，日落 | 缓慢推进 | 3s | 环境音 | 建立场景 |
| 2 | 中景 | 主角走在街头 | 跟拍 | 2s | 脚步声 | 引入人物 |
| 3 | 近景 | 主角回头看 | 固定 | 1s | 音乐起 | 制造悬念 |

### 短视频分镜模板
```
时间 | 画面 | 文案/旁白 | 音乐/音效
0-3s | 钩子画面 | "你知道吗？" | 悬疑音乐
3-8s | 展示问题 | 问题描述 | 背景音乐
8-25s | 解决方案 | 步骤讲解 | 节奏加快
25-30s | 结果展示 | "学到了吗？" | 音乐收尾
```

## 四、时间轴设计

### 镜头时长建议
| 场景类型 | 单镜头时长 | 剪辑节奏 |
|----------|-----------|----------|
| 动作/快节奏 | 1-2秒 | 快剪 |
| 对话/叙事 | 3-5秒 | 中等 |
| 抒情/氛围 | 5-10秒 | 慢剪 |
| 产品展示 | 2-4秒 | 中等 |

### 时间轴结构
```
[开场] 0-3秒：钩子，抓住注意力
[铺垫] 3-15秒：背景交代
[发展] 15-45秒：核心内容
[高潮] 45-55秒：最精彩的部分
[结尾] 55-60秒：总结/CTA
```

## 五、镜头节奏

### 节奏控制
- **快节奏**：短镜头、快剪、多动作
- **慢节奏**：长镜头、慢剪、少动作
- **变节奏**：快慢交替，制造起伏

### 音乐卡点
```
音乐节拍：  ↓   ↓   ↓   ↓
镜头切换：  | 1 | 2 | 3 | 4 |
```

- 在音乐节拍点切换镜头
- 制造节奏感和冲击力
- 适合MV、广告、短视频

## 六、蒙太奇手法

### 蒙太奇类型
| 类型 | 描述 | 适用 |
|------|------|------|
| 平行蒙太奇 | 多条线索同时进行 | 悬疑片、多线叙事 |
| 交叉蒙太奇 | 两条线索交替，制造紧张 | 追逐戏、对决 |
| 对比蒙太奇 | 对比画面，强化主题 | 社会议题、反差 |
| 隐喻蒙太奇 | 用画面暗示含义 | 文艺片、象征 |
| 积累蒙太奇 | 相似画面叠加 | 强调、积累情绪 |

### 蒙太奇案例
```
镜头1：婴儿出生
镜头2：小孩上学
镜头3：青年毕业
镜头4：中年工作
镜头5：老年回忆
→ 人的一生（积累蒙太奇）
```

## 七、短视频分镜技巧

### 竖屏分镜要点
- **主体居中**：竖屏核心区域在中间
- **上下留空**：顶部放标题，底部放CTA
- **近景为主**：竖屏适合近景和特写
- **大字幕**：手机屏幕小，字幕要大

### 短视频节奏
```
0-1秒：必须有画面变化（不能是静态）
1-3秒：钩子完成
3-10秒：第一个信息点
10-20秒：第二个信息点
20-30秒：第三个信息点+结尾
```

## 八、电影分镜案例分析

### 《盗梦空间》开场
```
1. 远景：海浪拍打沙滩（建立氛围）
2. 特写：陀螺旋转（引入关键道具）
3. 中景：主角被冲上岸（引入人物）
4. 近景：主角迷茫的表情（建立情绪）
5. 闪回：之前的画面（交代背景）
```

### 《寄生虫》楼梯场景
```
1. 全景：从豪宅往下走（阶层象征）
2. 中景：一家人走楼梯（动作）
3. 特写：雨水涌入（危机感）
4. 远景：低洼地区被淹（对比）
→ 用楼梯象征阶层，用雨水象征危机
```
