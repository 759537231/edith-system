# 交互动效设计

## 一、动效12原则（迪士尼动画原则在UI中的应用）

迪士尼的12动画原则是所有动效设计的基础：

### 1. 挤压与拉伸 (Squash & Stretch)
- **定义**：物体运动时的形变，表现弹性和重量感
- **UI应用**：按钮点击时轻微压缩，加载时弹性拉伸
- **参数**：scale 0.95-1.05，时长 100-200ms

### 2. 预备动作 (Anticipation)
- **定义**：动作前的反向蓄力
- **UI应用**：下拉刷新前的上拉、删除前的摇晃
- **参数**：预备时长为主动作的 20-30%

### 3. 演出 (Staging)
- **定义**：引导用户注意力到关键元素
- **UI应用**：新功能高亮、引导蒙层、呼吸灯效果
- **参数**：高亮持续 1-3 秒

### 4. 连续动作与姿态对应 (Straight Ahead & Pose to Pose)
- **定义**：连续动画 vs 关键帧动画
- **UI应用**：页面转场用关键帧，微动效用连续动画
- **参数**：关键帧间距 100-300ms

### 5. 跟随与重叠动作 (Follow Through & Overlapping)
- **定义**：不同部分以不同速度停止
- **UI应用**：列表滚动时的视差、元素错开出现
- **参数**：延迟 50-100ms，弹性衰减

### 6. 慢入慢出 (Slow In & Slow Out)
- **定义**：动作开始和结束时慢，中间快
- **UI应用**：所有转场动画、元素位移
- **缓动函数**：ease-in-out、cubic-bezier(0.4, 0, 0.2, 1)

### 7. 弧线 (Arcs)
- **定义**：自然运动沿弧线而非直线
- **UI应用**：FAB按钮展开、菜单弹出
- **参数**：贝塞尔曲线控制

### 8. 次要动作 (Secondary Action)
- **定义**：辅助主动作的附加动作
- **UI应用**：点赞时的心形粒子、加载时的背景渐变
- **参数**：不影响主流程，时长可长可短

### 9. 夸张 (Exaggeration)
- **定义**：适度夸张以增强表现力
- **UI应用**：错误状态的摇晃、成功的弹跳
- **参数**：幅度 10-30%，避免过度

### 10. 扎实的描绘 (Solid Drawing)
- **定义**：保持视觉一致性
- **UI应用**：动效符合物理规律、有重量感
- **参数**：考虑重力、摩擦力

### 11. 吸引力 (Appeal)
- **定义**：动效要令人愉悦
- **UI应用**：有趣的加载动画、品牌化微交互
- **参数**：符合品牌调性

### 12. 时间 (Timing)
- **定义**：动效时长和节奏
- **UI应用**：微交互 100-300ms，转场 300-500ms，复杂动画 500ms+
- **参数**：60fps 为目标

## 二、Material Design 动效规范

### 核心原则
- **真实运动**：符合物理规律
- **有目的**：每个动效都有意义
- **连续性**：保持视觉连续

### 缓动曲线
| 类型 | 曲线 | 用途 |
|------|------|------|
| Standard | cubic-bezier(0.4, 0, 0.2, 1) | 大多数转场 |
| Decelerate | cubic-bezier(0, 0, 0.2, 1) | 元素进入 |
| Accelerate | cubic-bezier(0.4, 0, 1, 1) | 元素退出 |

### 时长规范
| 场景 | 时长 |
|------|------|
| 微交互 | 100-150ms |
| 简单转场 | 200-300ms |
| 复杂转场 | 300-400ms |
| 全屏转场 | 400-500ms |

### 共享元素转场
- **定义**：两个页面间共享的元素平滑过渡
- **应用**：列表→详情的图片、标题
- **参数**：时长 300-400ms，标准缓动

## 三、iOS 动效规范

### 核心原则
- **自然**：符合直觉
- **流畅**：60fps
- **有意义**：帮助理解

### 弹簧动画
```swift
// iOS弹簧动画参数
UIView.animate(
    withDuration: 0.5,
    delay: 0,
    usingSpringWithDamping: 0.7,  // 阻尼 0-1，越小越弹
    initialSpringVelocity: 0.5,    // 初始速度
    options: .curveEaseInOut,
    animations: { ... }
)
```

### 时长规范
| 场景 | 时长 |
|------|------|
| 微交互 | 0.2-0.35s |
| 转场 | 0.35-0.5s |
| 复杂动画 | 0.5-0.75s |

## 四、微交互设计

### 定义
微交互是产品中围绕单个任务的小型交互时刻。

### 结构
1. **触发器** (Trigger)：用户操作或系统事件
2. **规则** (Rules)：交互的具体行为
3. **反馈** (Feedback)：用户看到/听到/感受到的
4. **循环与模式** (Loops & Modes)：重复和变化

### 常见微交互
| 交互 | 触发 | 反馈 | 示例 |
|------|------|------|------|
| 点赞 | 点击 | 心形弹跳+计数+1 | Twitter/微博 |
| 下拉刷新 | 下拉 | 旋转图标+进度指示 | 所有列表App |
| 滑动删除 | 左滑 | 背景色变红+删除按钮 | iOS邮件 |
| 收藏 | 点击 | 星标填充动画 | 浏览器书签 |
| 发送 | 点击 | 消息飞出+送达状态 | 微信/Telegram |

### 设计要点
- **即时反馈**：100ms 内响应
- **有意义**：帮助理解状态变化
- **不干扰**：不影响主要任务
- **一致**：相同操作相同反馈

## 五、过渡动画设计

### 页面转场类型
| 类型 | 描述 | 适用 |
|------|------|------|
| 淡入淡出 | 透明度变化 | 同级页面 |
| 滑入滑出 | 水平/垂直位移 | 层级关系 |
| 缩放 | 大小变化 | 进入/退出 |
| 共享元素 | 元素平滑过渡 | 列表→详情 |
| 模态 | 从底部升起 | 临时任务 |

### 转场设计原则
1. **表达层级**：进入=前进（从右），返回=后退（从左）
2. **保持连续**：用户要知道从哪来到哪去
3. **控制时长**：300-500ms，太短看不清，太长等不及
4. **减少干扰**：转场是过渡，不是表演

## 六、骨架屏与加载动画

### 骨架屏 (Skeleton Screen)
- **定义**：内容加载前显示的占位UI
- **优点**：减少感知等待时间、预示内容结构
- **实现**：灰色矩形+闪烁动画

### 骨架屏设计规范
| 元素 | 形状 | 动画 |
|------|------|------|
| 文本行 | 灰色矩形 | 左右渐变闪烁 |
| 头像 | 灰色圆形 | 左右渐变闪烁 |
| 图片 | 灰色矩形 | 左右渐变闪烁 |
| 按钮 | 灰色圆角矩形 | 左右渐变闪烁 |

### 加载动画类型
| 类型 | 描述 | 适用 |
|------|------|------|
| Spinner | 旋转圆圈 | 短时间加载 |
| 进度条 | 百分比指示 | 可预知进度 |
| 骨架屏 | 内容占位 | 列表/详情页 |
| 品牌动画 | Logo动画 | 启动/App切换 |
| 下拉刷新 | 自定义动画 | 列表刷新 |

### 加载策略
```
加载时间判断
  ├── < 100ms → 无需反馈
  ├── 100ms - 1s → Spinner/骨架屏
  ├── 1s - 5s → 进度条 + 骨架屏
  ├── 5s - 10s → 进度条 + 提示文字
  └── > 10s → 进度条 + 取消按钮 + 预计时间
```

## 七、动效参数速查

### 时长速查
| 场景 | 时长 | 缓动 |
|------|------|------|
| 按钮点击 | 100-150ms | ease-out |
| Toast出现 | 200-300ms | ease-in-out |
| 页面转场 | 300-500ms | ease-in-out |
| 模态弹出 | 300-400ms | spring |
| 列表加载 | 50-100ms/项 | stagger |
| 骨架屏闪烁 | 1.5-2s | ease-in-out |

### 弹簧参数速查
| 效果 | Damping | Velocity | Duration |
|------|---------|----------|----------|
| 轻微弹跳 | 0.8 | 0.5 | 0.4s |
| 中等弹跳 | 0.6 | 0.5 | 0.5s |
| 强弹跳 | 0.4 | 0.5 | 0.6s |
| 无弹跳 | 1.0 | 0.5 | 0.3s |

### 缓动函数速查
```css
/* 标准 */
ease: cubic-bezier(0.25, 0.1, 0.25, 1)
ease-in: cubic-bezier(0.42, 0, 1, 1)
ease-out: cubic-bezier(0, 0, 0.58, 1)
ease-in-out: cubic-bezier(0.42, 0, 0.58, 1)

/* Material Design */
standard: cubic-bezier(0.4, 0, 0.2, 1)
decelerate: cubic-bezier(0, 0, 0.2, 1)
accelerate: cubic-bezier(0.4, 0, 1, 1)

/* 弹性 */
bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55)
```
