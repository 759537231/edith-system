# Qwen3.5-4B 模型行为分析

## 模型特性

### 输出格式
- **思考模式**：默认开启，输出详细推理步骤
- **输出结构**：Thinking Process + 编号步骤 + 最终答案
- **语言**：中英混合，思考过程多为英文

### 思考过程格式
```
Thinking Process:

1.  **Analyze the Request:**
    *   Topic: ...
    *   Constraint: ...

2.  **Define ...:**
    *   Core concept: ...

3.  **Drafting ...:**
    *   *Draft 1:* 中文答案 (English translation)
    *   *Draft 2:* 中文答案 (English translation)
```

### 关键特征
- 思考过程占 60-80% 的 token
- 实际答案在最后几个 Draft 中
- 中文答案通常在括号前

## 参数优化

### 最佳参数配置
```python
# 平衡版（推荐）
{
    "temperature": 0.65,
    "top_p": 0.85,
    "min_p": 0.05,
    "max_tokens": 1536
}

# 推理任务
{
    "temperature": 0.5,
    "top_p": 0.8,
    "min_p": 0.05,
    "max_tokens": 1536
}

# 创意任务
{
    "temperature": 0.8,
    "top_p": 0.95,
    "min_p": 0.03,
    "max_tokens": 2048
}
```

### 参数影响
- **temperature**：越低越稳定，越高越有创意
- **top_p**：控制词汇多样性
- **min_p**：过滤低质量 token
- **max_tokens**：太小会导致答案被截断

## 已知问题

### 1. 思考过程过多
- **现象**：模型输出大量思考步骤，实际答案很少
- **影响**：测试评估不准确，质量评分下降
- **解决**：使用过滤函数提取实际答案

### 2. 答案被截断
- **现象**：max_tokens 太小，答案不完整
- **影响**：质量评分下降
- **解决**：增加 max_tokens 到 1536-2048

### 3. 角色选择不当
- **现象**：选择了不适合任务的角色
- **影响**：质量评分下降
- **解决**：根据任务类型选择最佳角色
