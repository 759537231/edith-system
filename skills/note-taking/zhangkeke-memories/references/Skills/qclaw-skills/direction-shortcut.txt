# 分享位置+方向快捷指令

## 创建步骤

1. 打开「快捷指令」App
2. 点击右上角「+」新建
3. 添加以下动作：

### 动作 1：获取当前位置
- 搜索「位置」→ 选择「获取当前位置」
- 精确度：高

### 动作 2：获取设备方向
- 搜索「获取设备详情」→ 选择「获取设备详情」
- 选择「航向」或「方向」

### 动作 3：格式化文本
- 搜索「文本」→ 选择「文本」
- 内容：
```
📍 位置：{纬度}，{经度}
🧭 朝向：{航向}
🗺️ 地图：https://apis.map.qq.com/uri/api/marker?coord_type=gcj02&referer=我的应用&marker=lat:{纬度},lng:{经度},title:我的位置
```

### 动作 4：拷贝到剪贴板
- 搜索「拷贝」→ 选择「拷贝到剪贴板」

4. 保存命名为「分享位置和方向」

## 使用方法
- 打开快捷指令 → 点击运行
- 自动获取位置+方向+地图链接
- 粘贴给我

## 效果示例
📍 位置：31.6143，120.2021
🧭 朝向：北偏东 45°
🗺️ 地图：点击打开腾讯地图
