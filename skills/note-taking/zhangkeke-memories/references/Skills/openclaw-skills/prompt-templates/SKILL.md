# 📋 Prompt Templates — 轻量模型协作最佳实践

> 核心原则：**模型不需要"知道"，只需要"看到"。**
> 把格式、背景、示例直接给到位，减少模型猜测。

## 五大模板库

| 模板 | 触发词 | 路径 |
|------|--------|------|
| 🧾 记账 | "记账"/"花了"/"识别账单" | `templates/记账模板.md` |
| 📊 分析 | "分析"/"帮我看看"/"对比" | `templates/分析模板.md` |

## 使用方式

调用模板时，直接把模板内容作为Prompt的前缀 + 加上你的具体任务。

示例：
```
用户：「帮我分析一下这个项目的可行性」

→ 先读取 templates/分析模板.md
→ 把模板前缀 + 用户具体问题组合成最终prompt
→ 发送给模型
```

## 通用原则（所有模板适用）

1. **先给背景**：这件事的上下文是什么
2. **再给格式**：你要什么形式的输出
3. **最后给任务**：具体要做什么
4. **必要时给示例**：参考格式是什么样的

## 模板质量标准

每个模板必须包含：
- ✅ **触发条件**：什么时候用这个模板
- ✅ **Prompt前缀**：固定的引导语
- ✅ **输出格式**：明确的结构要求
- ✅ **Few-shot示例**（可选）：输入-输出对
- ✅ **注意事项**：常见错误和避坑指南
