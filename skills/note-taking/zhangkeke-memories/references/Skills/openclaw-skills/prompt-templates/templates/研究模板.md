# 🔍 研究模板

## 触发条件

用户说：
- 「调研一下」「了解一下」「查一下」
- 「有什么关于XX的信息」「最近XX怎么样了」
- 「帮我找」「搜一下」

## 研究任务分类

### 快速概览（信息收集）
```
任务：快速了解 [具体主题]

请按以下结构整理信息：

1. 核心结论（一句话）
2. 基本情况（是什么，有哪些）
3. 关键点（3-5个，每点一句话）
4. 信息来源（你搜到的网页标题+链接）

要求：
- 区分"事实"和"观点"
- 事实给来源，观点给来源+立场
- 如果搜不到有价值的信息，直接说"未找到相关信息"
- 不要脑补，不知道就说不知道
```

### 深度研究（需要分析）
```
主题：[具体研究问题]
研究目的：[用户想知道什么，用于什么决策]

请按以下步骤进行：

第一步：收集背景信息
- 基本定义和概念
- 历史脉络（近3-5年）
- 主要玩家/方案/流派

第二步：分析整理
- 各方案的优劣势对比
- 当前主流趋势
- 潜在风险或隐患

第三步：结论和建议
- 基于以上分析，给出你的判断
- 标明信息的置信度（有把握 vs 推测）

格式：要点式，不超过2000字
```

### 对比研究（选项分析）
```
对比项：[A vs B vs C]

请从以下维度对比：

| 维度 | A | B | C |
|------|---|---|---|
| 核心特点 | | | |
| 主要优点 | | | |
| 主要缺点 | | | |
| 适用场景 | | | |
| 参考价格/成本 | | | |
| 获取难度 | | | |

结论：[哪个更适合什么场景]

信息来源：每个结论注明来源网页
```

## 信息质量判断

研究时注意区分：

| 类型 | 特征 | 可信度 |
|------|------|--------|
| 官方发布 | 政府网站、大厂文档 | 高 |
| 权威媒体 | 主流媒体报道 | 中高 |
| 行业报告 | 付费报告摘要 | 中 |
| 社区讨论 | 论坛、Reddit、微博 | 中低 |
| 个人博客 | 个人网站 | 低 |
| 无来源声明 | 纯推测 | 低 |

## 注意事项

- 轻量模型的知识截止日期有限，联网搜索优先
- 搜索结果要整理，不要直接把原始结果丢给用户
- 涉及选择/推荐时，给出判断但说明依据，让用户自己决定
- 长篇研究内容，输出前先摘要给用户看，用户说"详细"再展开
