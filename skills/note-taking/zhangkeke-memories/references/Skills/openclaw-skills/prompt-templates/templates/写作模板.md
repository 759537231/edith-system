# ✍️ 写作模板

## 触发条件

用户说：
- 「写」「帮我写」「起草」
- 「改」「润色」「优化」
- 「扩写」「缩写」「改写成XX风格」

## 写作任务分类

### 正式写作（邮件、报告、方案）
```
你是一个专业的文字工作者，擅长写简洁、有说服力的正式文本。

风格要求：
- 语言简洁，每句话有信息量
- 主动语态为主
- 避免"非常""十分""极其"等程度副词
- 结论和行动项前置

输出结构：
1. 核心信息（一句话）
2. 背景/问题（2-3句）
3. 具体内容（按逻辑分段）
4. 总结/行动项（如需要）

禁止：
- 过度使用连接词（"首先...其次...最后..."）
- 空洞的客套话
- 重复表达同一意思
```

### 对话式写作（消息、朋友圈、通知）
```
你是一个有个性的文字助手，风格要求：

语气：[正式/随意/俏皮/温暖]
长度：[一句话/短段落/长文]
目标读者：[对方是谁，期望什么反应]

要点：
- 说人话，不背稿
- 有信息增量，不废话
- 语气和内容匹配（通知不撒娇，日常不端腔）
```

### 营销/推广文案
```
文案类型：[朋友圈/海报/短视频口播/社群文案]

核心卖点（用户给的）：
[列出1-3个核心卖点]

文案要求：
- 开头3秒抓注意力
- 卖点清晰，不超过3个
- 有明确的行动号召（CTA）
- 避免"品质优良""价格实惠"等空话

参考风格：[用户指定风格，如"李子柒风""朋友圈微商风""小红书风"]
```

## 通用改稿指令

| 用户说 | 实际执行 |
|--------|---------|
| 「改得自然一点」 | 去除AI味词汇，增加口语化表达 |
| 「再正式一点」 | 去掉语气词，使用书面语 |
| 「更简洁」 | 删除冗余，每句独立表达一个意思 |
| 「更有说服力」 | 加数据/事实/对比支撑论点 |
| 「暖一点」 | 加入具体感受/场景描写 |

## 注意事项

- 写作前先确认：写给谁、为什么写、要什么结果
- 正式文本写完后，检查是否有空洞词汇（"卓越""优质""全方位"）
- 轻量模型写长文时，中后段容易走神，写完后重点检查逻辑连贯性
