# 💻 代码模板

## 触发条件

用户说：
- 「写代码」「帮我写」「Python/JavaScript/Shell...」
- 「这个报错」「帮我debug」「修复」
- 「自动化」「做个脚本」

## 通用代码Prompt

```
你是Python/Shell脚本开发专家。

要求：
1. 代码可以直接运行（假设环境已安装必要库）
2. 中文注释，说明关键逻辑
3. 错误处理要完整
4. 函数单一职责，命名自解释

输出格式：
```python
# 文件名：xxx.py
# 功能：...

import ...

def main():
    ...

if __name__ == "__main__":
    main()
```

常见任务参考：

### 数据处理任务
```
任务：[描述具体要做什么]
输入数据格式：[CSV/JSON/Excel/...]
输出要求：[目标格式和结构]
特殊处理：[有没有边界情况要处理]

要求：pandas优先，处理大文件时考虑分块读取
```

### 自动化脚本任务
```
任务：[描述要自动化什么]
触发条件：[手动运行/定时/Cron]
运行环境：[macOS/Linux/跨平台]

要求：
- 详细的运行说明（依赖安装、参数说明）
- 日志输出，标明执行进度
- 如果出错，打印错误信息并给出解决建议
```

### 调试任务
```
错误信息：[粘贴报错内容]
相关代码：[提供代码片段或文件路径]

请按以下步骤分析：
1. 先理解报错信息（指出具体是哪一行/什么类型的错误）
2. 分析可能原因（列出2-3个最常见的原因）
3. 给出修复代码
4. 说明为什么这样修复
```

## 注意事项

- 轻量模型写简单脚本能力足够，但复杂逻辑（多线程、异步、并发）容易出错
- 代码写完后，如果涉及文件读写或网络请求，提示用户先在测试环境运行
- 涉及中文路径或中文文件名时，检查编码处理（utf-8、gbk适配）
- Mac上的shell脚本注意shebang和执行权限
