# 🥊 双模型辩论 Skill

## 触发词

「辩论」「两个模型讨论一下」「对抗分析」「正反方讨论」

## 工作原理

两个 AI 模型对同一问题进行 1-2 轮辩论：
- **小米 mimo-v2.5-pro**：正方（支持/乐观/技术视角）
- **LongCat**：反方（反对/悲观/风险视角）

## 执行流程

### Step 1：确定辩题

用户提出问题，我将其转化为辩题。

示例：
- 用户：AI 会取代人类工作吗？
- 辩题：**正方：AI 将大规模取代人类工作 / 反方：AI 不会大规模取代人类工作**

### Step 2：第一轮辩论

**正方（小米）**：
```
delegate_task(
    goal="你是正方辩手。请对以下辩题发表你的立场和论点（200字以内）。\n\n辩题：{辩题}\n你的立场：{正方立场}\n\n要求：\n1. 明确亮出立场\n2. 给出2-3个核心论点\n3. 每个论点有事实或逻辑支撑\n4. 语气坚定但不极端",
    context="正方辩手，小米模型"
)
```

**反方（LongCat）**：
```
delegate_task(
    goal="你是反方辩手。请对以下辩题发表你的立场和论点（200字以内）。\n\n辩题：{辩题}\n你的立场：{反方立场}\n\n要求：\n1. 明确亮出立场\n2. 给出2-3个核心论点\n3. 每个论点有事实或逻辑支撑\n4. 语气坚定但不极端",
    context="反方辩手，LongCat模型"
)
```

### Step 3：第二轮交锋（可选）

**正方回应**：
```
delegate_task(
    goal="你是正方辩手。对方提出了以下反驳，请回应（150字以内）。\n\n原辩题：{辩题}\n你的原论点：{正方第一轮}\n对方反驳：{反方第一轮}\n\n要求：\n1. 直接回应对方论点\n2. 指出对方漏洞（如有）\n3. 强化自己的立场",
    context="正方第二轮回应"
)
```

**反方回应**：
```
delegate_task(
    goal="你是反方辩手。对方提出了以下反驳，请回应（150字以内）。\n\n原辩题：{辩题}\n你的原论点：{反方第一轮}\n对方反驳：{正方第一轮}\n\n要求：\n1. 直接回应对方论点\n2. 指出对方漏洞（如有）\n3. 强化自己的立场",
    context="反方第二轮回应"
)
```

### Step 4：裁判总结

我（小米）作为裁判，给出总结：
- 双方核心分歧点
- 各自的强项和弱项
- 综合判断（不和稀泥，给明确观点）

```markdown
## 🥊 辩论：{辩题}

### 第一轮

**🔵 正方（小米）**：{正方立场}
> {正方论点}

**🔴 反方（LongCat）**：{反方立场}
> {反方论点}

### 第二轮（如有）

**🔵 正方回应**：
> {正方回应}

**🔴 反方回应**：
> {反方回应}

### 🏛️ 裁判总结

**核心分歧**：{双方根本分歧}

**正方强项**：{正方优势}
**正方弱项**：{正方漏洞}

**反方强项**：{反方优势}
**反方弱项**：{反方漏洞}

**综合判断**：{我的明确观点}
```

## 使用示例

```
你：AI 会取代人类工作吗？辩论一下
我：好，我来安排一场辩论。
  ↓
  正方（小米）：AI 将大规模取代...
  反方（LongCat）：AI 不会大规模取代...
  ↓
  正方回应：对方忽视了...
  反方回应：对方过于乐观...
  ↓
我（裁判）：核心分歧在于...
```

## 适用场景

- 重大决策前的正反思考
- 技术选型的利弊分析
- 投资判断的风险评估
- 任何需要多角度思考的问题

---

## ⚠️ 辩论 vs 商讨（重要区分）

**用户明确要求：不要形式上的辩论，要真正的商讨。**

| 维度 | model-debate（辩论） | model-discussion（商讨） |
|------|---------------------|------------------------|
| 目标 | 争输赢 | 求共识 |
| 语气 | 对抗性 | 协作性 |
| 结果 | 裁判判定胜负 | 共同结论 |
| 用户偏好 | ❌ 不常用 | ✅ 默认使用 |

**默认行为**：大多数任务应使用 `model-discussion`（商讨），而非辩论。
辩论仅在用户明确说"辩论""正反方""对抗分析"时触发。

**商讨 skill**：`autonomous-ai-agents/model-discussion`
