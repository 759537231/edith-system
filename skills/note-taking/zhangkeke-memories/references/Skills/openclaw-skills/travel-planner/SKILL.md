# 自驾旅行规划 Skill

## 核心原则

**车能到的地方都去，不爬山，简单溜达。**

这个skill是用来生成自驾旅行攻略表格的，不是用来订酒店买门票的。

## 工作流程

### Step 1: 发送前置问卷

用户触发后，先发送前置问卷收集信息。问卷内容见 `references/questionnaire.md`。

### Step 2: 等待用户回复

问卷必填项：
- 出发地
- 目的地/想去的区域
- 出行日期和天数
- 同行人数
- 预算范围
- 交通方式（自驾/公共交通）
- 体力偏好（爬不爬山）
- 收费景点态度

选填项可在后续补充。

### Step 3: 生成攻略表格

信息齐全后，生成xlsx表格。表格结构见 `references/template-structure.md`。

生成表格的脚本在 `scripts/generate_travel.py`，可以直接调用或参考。

### Step 4: 交付表格

表格保存到用户桌面，文件名格式：`XX旅行自驾攻略（X天X晚）.xlsx`

## 必备能力

- 路线规划（车程、路况）
- 景点筛选（体力要求、收费情况）
- 住宿推荐（价格区间、预订方式）
- 费用估算
- 备案方案

## 禁止行为

- 不帮用户订酒店、买门票
- 不推荐需要长时间徒步的景点（除非用户明确要求）
- 不提供虚假的票价/电话信息
