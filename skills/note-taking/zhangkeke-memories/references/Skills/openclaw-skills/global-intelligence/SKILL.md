## 核心设计哲学

1. **准确是唯一标准** — 不是为了自嗨，不是为了看起来严谨，是对准真实
2. **冲突区不默认乐观** — 活跃冲突区短期预测基线：现状延续40% + 升级30% + 缓和30%
3. **政治摩擦力必须建模** — 理性博弈假设必须经过Politico压力测试
4. **概率修正可上可下** — Politico不是唱反调，是校准；可能上调也可能下调

## 执行流程（4步，主会话执行）

### Step 1：情报抓取（多源搜索 + 全文抓取）

**方式一：自动搜索计划（推荐）**

```bash
cd ~/.hermes/skills/note-taking/zhangkeke-memories/references/Skills/openclaw-skills/global-intelligence
python3 scripts/aggregator.py "{topic}"
```

输出 JSON 搜索计划，包含：
- 中英文双语关键词
- 3轮搜索（最新动态/深度分析/国际视角）
- 每轮的搜索词

**方式二：手动执行搜索**

按以下步骤执行：

1. **生成搜索计划**：
```bash
python3 scripts/aggregator.py "{topic}"
```

2. **执行搜索**（按计划中的 queries 逐个搜索）：
```
web_search(keyword="中美局势 最新消息 今日")
web_search(keyword="US-China relations latest news")
```

3. **筛选高质量文章**（从搜索结果中选择5-8篇）

4. **抓取全文**：
```
web_extract(url="https://example.com/article1")
web_extract(url="https://example.com/article2")
```

5. **汇总分析**（注意平衡国内外视角）

**搜索质量要求**：
- 中文源至少3条（国内媒体/智库/专家）
- 英文源至少3条（国际媒体/智库/专家）
- 全文抓取至少3篇（深度分析用）
- 优先抓取：Reuters、BBC、NYT、财新、澎湃、观察者网

**输出**：情报 JSON + 全文内容，主会话直接持有

## 冲突区双基线规则

**判定条件**（满足任一）：
- 活跃武装冲突正在进行
- 停火协议脆弱（签署<30天或违反>3次）
- 升级阶梯已启动（军事部署/动员/封锁）

**双基线概率**：
- 现状延续：40%
- 随机升级：30%
- 降级缓和：30%（需强降温信号：双边停火+国际监督+领导人承诺）

**强降温信号**（三者缺一不可）：
1. 双边停火协议签署
2. 国际监督机制到位
3. 双方领导人公开承诺

## 月度反馈校准闭环

1. 每月1日，对比上月报告预测 vs 实际发展
2. 偏乐观专家（连续3次高估缓和）→ 降权10%
3. 偏悲观专家（连续3次低估缓和）→ 降权10%
4. Politico校验准确率纳入评估
5. 历史误判规则注入专家prompt
