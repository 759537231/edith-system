# 🌍 Global Intelligence

全球局势分析系统 — 8维专家并行分析 + 双犹太智囊推演

## 快速开始

```bash
# 安装
cd ~/.hermes/skills/note-taking/zhangkeke-memories/references/Skills/openclaw-skills/global-intelligence
bash install.sh

# 使用
global-intel '中美AI竞争'              # 完整分析
global-intel '俄乌局势' -q             # 快速扫描
global-intel '台海局势' -p 高          # 高优先级报告
```

```
用户查询
    │
    ▼

                  │
    ┌─────────────┼─────────────┐
    ▼             ▼             ▼
┌───────┐    ┌───────┐    ┌───────┐
│ 8维专家 │    │ 8维专家 │    │ 8维专家 │  ... (并行)
└───┬───┘    └───┬───┘    └───┬───┘
    │             │             │
    └─────────────┼─────────────┘
                  ▼
┌─────────────────────────────────────────┐

│  报告生成器 (reporter.py)                │
│  整合 → 结构化 → 输出                    │
└─────────────────────────────────────────┘
```

## 8维专家

| 代号 | 专家 | 维度 | 核心能力 |
|------|------|------|---------|
| 🗺️ | Atlas | 地缘战略 | 大国博弈、势力范围、联盟变迁 |
| 💰 | Plutus | 经济金融 | 全球宏观、产业链、金融流动 |
| 🛡️ | Sentinel | 安全情报 | 军事冲突、地区动荡、恐怖主义 |
| ⚡ | Tesla | 科技竞争 | 技术封锁、AI竞争、航天博弈 |
| ⛽ | Prometheus | 能源资源 | 油气、新能源、战略储备 |
| 📢 | Echo | 舆情监测 | 社媒情绪、舆论战、认知作战 |
| 📜 | Chronos | 历史对照 | 历史类比、周期规律、教训提取 |
| 🐉 | Dragon | 中国影响 | 对华直接影响、反制选项、机会窗口 |

## 定时任务

编辑 `config/cron.json` 启用每日简报：

```json
{
  "enabled": true,
  "schedule": "0 8 * * *",
  "topics": ["中美局势", "全球经济", "科技竞争"]
}
```
