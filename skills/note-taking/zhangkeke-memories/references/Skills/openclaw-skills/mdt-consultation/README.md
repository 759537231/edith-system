# 联合会诊 Skill — 使用文档

## 快速开始

### 启动会诊
发送消息：
```
联合会诊
```

系统进入**前台医导**对话模式，开始采集病史。

### 结束会诊
任意时刻发送：
```
结束会诊
回到壳壳
```

## 完整流程示例

**用户**：联合会诊

**系统（前台医导）**：您好，请问您哪里不舒服？

**用户**：我头痛，眼睛也不舒服

**系统**：头痛是什么时候开始的？是持续疼还是阵发性的？

...（多轮对话采集）...

**用户**：开始会诊

**系统**：
```
【结论】
视盘水肿伴颅内压增高可能

【方案A：神经科紧急排查】[B]
• 做什么：颅脑MRI+MRV+腰穿测颅压
• 怎么做：神经内科就诊，开具检查
• 去哪做：三甲医院神经内科
• 医生需确认：是否有静脉窦血栓高危因素

【方案B：眼科随访监测】[C]
• 做什么：视野检查+OCT-RNFL基线
• 怎么做：眼科就诊，建立基线数据
• 去哪做：眼科
• 医生需确认：视盘水肿是否为真性水肿

【方案C：中医辅助调理】[D]
• 做什么：天麻钩藤饮加减
• 怎么做：辨证后使用
• 去哪做：中医科
• 医生需确认：与西药无相互作用

【问医生】
1. 需不需要紧急做MRI？
2. 视盘水肿是真性还是假性？

需要完整的PDF诊断书吗？
```

## 适用场景

✅ **推荐启动**：
- 症状涉及多个系统（如头痛+视力+情绪）
- 单一专科无法解释全部症状
- 希望获得中西医结合的综合建议
- 需要循证医学支持的第二意见
- 术后/损伤后功能恢复方案

❌ **不推荐启动**：
- 单一明确问题（如单纯近视验光）
- 急危重症需立即就医（直接去医院）
- 仅需简单健康咨询

## 六大学科分工

| 学科 | 专长领域 | 输出特点 |
|------|---------|---------|
| 眼科 | 眼底病变、屈光、眼压 | 影像解读、器质性排查 |
| 神经科 | 脑-神经-行为整合 | 病变定位、影像分析 |
| 神经眼科 | 视路交叉地带、功能性视觉障碍 | 器质vs功能鉴别、客观检查解读 |
| 康复科 | 功能恢复方案、神经可塑性 | 阶段化康复训练、预期评估 |
| 心理科 | 心身医学、情绪障碍 | DSM-5诊断、循证干预 |
| 中医 | 整体辨证、调理 | 传统+现代双轨输出 |

## 动态分科

不是每次都凑6科。根据症状模式按需组合：

| 症状模式 | 参与科室 |
|---------|---------|
| 单纯眼部问题 | 眼科 |
| 眼+神经系统 | 眼科+神经科+神经眼科 |
| 视觉症状+注意力/情绪相关 | 神经眼科+心理科+康复科 |
| 术后/损伤后功能恢复 | 眼科+康复科+（神经眼科） |
| 多系统+全身调理 | 全科+中医 |
| 复杂/不典型 | 神经眼科+神经科+眼科+康复科 |

## 证据等级说明

每句医学建议后标注证据等级：

- **[A]** — 系统综述/Meta分析/随机对照试验（最高）
- **[B]** — 队列研究/病例对照研究
- **[C]** — 专家共识/临床指南
- **[D]** — 传统理论/临床经验（最低）

## 重要免责声明

1. **不能替代面诊**：本系统仅为信息整合工具，不能替代执业医师的诊断和治疗
2. **紧急情况**：如出现剧烈头痛、视力骤降、意识改变等，请立即前往急诊
3. **用药安全**：中药、西药均需在专业医师指导下使用
4. **隐私保护**：病史信息仅用于本次会诊，不存储个人身份信息

## 技术架构

```
用户对话
  ↓
前台医导（自然语言采集，支持快速/逐条两种模式）
  ↓
兵部结构化（JSON病例）
  ↓
多专家并行分析（按需组合1-6科，JSON交流）
  ↓
枢密院整合（结论+方案先行，PDF按需）
  ↓
用户
```
