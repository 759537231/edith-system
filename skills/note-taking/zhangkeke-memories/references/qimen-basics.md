## 核心概念

### 什么是奇门遁甲
中国古代"三式"之一（太乙、六壬、奇门），被认为是最高层次的术数。古代用于行军打仗，现代用于择日、出行、寻物、测吉凶。

### 三奇六仪
- 三奇：乙、丙、丁
- 六仪：戊、己、庚、辛、壬、癸
- 遁甲：甲不直接出现，藏在六仪之下

### 八门（核心）
| 门 | 吉凶 | 五行 | 含义 |
|----|------|------|------|
| 开门 | 吉 | 金 | 开创、通达 |
| 休门 | 吉 | 水 | 休息、安逸 |
| 生门 | 吉 | 土 | 生机、财利 |
| 伤门 | 凶 | 木 | 伤害、损失 |
| 杜门 | 中 | 木 | 隐藏、闭塞 |
| 景门 | 中 | 火 | 光明、文书 |
| 死门 | 凶 | 土 | 绝望、终结 |
| 惊门 | 凶 | 金 | 惊恐、意外 |

**三吉门：开、休、生**
**三凶门：死、惊、伤**

## 以自身定中宫（活盘）

### 核心规则
以自己为中心，相对方位定八宫：

| 你的位置 | 宫位 | 卦 |
|----------|------|-----|
| 面朝方向 | 前 | 离 |
| 背后 | 后 | 坎 |
| 左手 | 左 | 震 |
| 右手 | 右 | 兑 |
| 左前方 | 左前 | 巽 |
| 右前方 | 右前 | 坤 |
| 左后方 | 左后 | 艮 |
| 右后方 | 右后 | 乾 |

**关键：前=离是约定俗成，不需要问为什么。** 就像红灯停绿灯行，是规矩。

### 天禽星寄宫
- 阳遁：寄坤二宫
- 阴遁：寄艮八宫
- 中宫是虚位，不单独排门

### 活盘用法
1. 站定 → 中宫
2. 面朝方向 → 前（离）
3. 看到什么 → 取象
4. 象落哪个方位 → 定宫
5. 五行生克 → 断吉凶

### 两种用法
- **主动选择**：要出门，看八方哪个吉，选那个方向
- **被动取象**：事情已发生，看发生在哪个方位，断吉凶

## 简化排盘法（创新尝试）

### 用户需求
- 不想查万年历
- 不想背太多东西
- 主要用途：找东西、测吉凶、定心

### 日时定门法
用日干 + 时辰定门，不排盘。

**日干 → 值使门：**
| 日干 | 值使门 |
|------|--------|
| 甲 | 休门 |
| 乙 | 生门 |
| 丙 | 伤门 |
| 丁 | 杜门 |
| 戊 | 景门 |
| 己 | 死门 |
| 庚 | 惊门 |
| 辛 | 开门 |
| 壬 | 休门 |
| 癸 | 生门 |

**时辰 → 值使门落宫：**
| 时辰 | 落宫 |
|------|------|
| 子时 | 坎 |
| 丑时 | 艮 |
| 寅时 | 震 |
| 卯时 | 巽 |
| 辰时 | 离 |
| 巳时 | 坤 |
| 午时 | 兑 |
| 未时 | 乾 |
| 申时 | 坎（循环） |
| 酉时 | 艮 |
| 戌时 | 震 |
| 亥时 | 巽 |

值使门定了，其他七门按"休生伤杜景死惊开"顺序排。

## 落地用途

1. **寻物**：看生门落哪个宫 → 那个方向找
2. **测吉凶**：看吉门（开休生）落哪个宫 → 那个方位有利
3. **出行**：选吉门方位走
4. **择日**：选吉时办事
5. **谈判**：选座位方位

## 常见误区

1. **左右不分** → 差一个方位结论完全不同（巽宫木木比和 vs 坤宫木克土）
2. **取象和落宫混为一谈** → 取象看五行，落宫看方位，是两回事
3. **手算排盘** → 复杂排盘用软件或代码，手算容易错
4. **问"为什么前=离"** → 是约定，不是道理，不用深究
