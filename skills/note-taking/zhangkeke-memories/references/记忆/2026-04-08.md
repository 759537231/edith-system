## 冲突分析与解决

### 发现的问题
1. 创建的 `utils/*.ts` 文件是独立静态文件
2. QClaw/OpenClaw 不会自动加载和执行
3. 需要集成到运行时才能生效

### 解决方案
- 将功能封装成 Skill
- 放入 `~/.openclaw/workspace/skills/`
- OpenClaw 自动加载

## 启示

### Claude Code 架构亮点
1. **编译时裁剪** - Bun feature() 实现零性能损耗
2. **Generator 流式** - 用户体验极佳
3. **权限分层** - 多模式切换灵活

### QClaw 差异化路线
1. **运行时配置** - 更灵活，用户可自定义
2. **Skill 动态加载** - 比 Claude Code 的静态工具更灵活
3. **Session 隔离** - 多Agent路线不同

### 融合原则
- 不照搬，取精华
- 适配 QClaw 架构
- 封装成 Skill 实现自动加载

### 权限系统设计要点

1. **三种权限模式**
   - `default`：危险操作需确认
   - `plan`：只读操作可用
   - `auto`：白名单操作自动执行

2. **四个权限级别**
   - `read`：只读
   - `write`：写入
   - `execute`：执行
   - `admin`：管理

3. **配置文件扩展**
   - 在 `openclaw.json` 中增加 `permissions` 字段

### 流式查询设计要点

1. **AsyncGenerator 封装**
   - 流式调用 API
   - 实时解析消息

2. **消息类型**
   - `text`：文本片段
   - `thinking`：思考片段
   - `tool_call`：工具调用
   - `tool_result`：工具结果

3. **前端渲染**
   - 增量文本更新
   - 打字机效果
   - 中断和恢复
