## 完成内容

### 1. Zvec API 深度实测

实测发现 Zvec v0.3.0 有严重的文档与实现不符问题。摸清了以下关键规则：

| 规则 | 文档写法 | 实测正确写法 |
|------|---------|------------|
| 主键类型 | 可以是 int | 必须 STRING（int 会报 TypeError） |
| 设置字段 | doc.set_string/set_int | doc.fields['key'] = value |
| 设置向量 | doc.set_vector | doc.vectors['key'] = np.array |
| 插入 | col.add / col.insert | col.upsert([doc]) + flush() |
| 查询参数 | vector=... limit=... | vectors=[VectorQuery(...)], topk=... |
| 查询向量 | vector=np.array | 必须 list（np.array 有 bool 检查 bug） |
| 创建目录 | 需先 mkdir | zvec.create_and_open() 自动创建 |
| 集合关闭 | col.close() | 不存在此方法 |

### 2. vector_store.py 模块（10KB）

功能：
- `embed_text()` — 多后端嵌入（OpenAI → DashScope → MLX → 随机降级）
- `store_report()` — 存储分析报告（id/title/topic/priority/timestamp/summary + 向量）
- `search_similar()` — 语义检索（支持 topic 过滤）
- `build_index()` — HNSW 索引构建
- `stats()` — 状态查询

Schema 设计：
- id: STRING（PK）
- title: STRING
- topic: STRING（分类：科技/地缘/经济/能源/综合）
- priority: STRING
- timestamp: DOUBLE
- summary: STRING（用于嵌入，限制2000字符）
- embedding: VECTOR_FP32(1536)
