## 23:11 - ProSearch搜索工具讨论

**背景**：用户问ProSearch是什么、是否可以独立运行

**ProSearch本质**：
- QClaw内置联网搜索工具，通过Node.js脚本调用本地HTTP代理 `/proxy/prosearch`
- 认证由QClaw网关自动处理，基于用户登录态，无需手动配置
- 无需额外安装，所有QClaw用户直接可用
- 集成17个搜索引擎（8国内+9国际），支持高级搜索语法、时间筛选、站内搜索

**用户需求**：想做一个可以独立运行的搜索入口（不依赖QClaw对话界面）

**方案A：继续用QClaw的ProSearch，搭一个独立调用脚本**
- 逻辑和GI Skill的aggregator.py类似
- 优点：保持现状，无需额外配置
- 缺点：离不开QClaw网关在运行

**方案B：部署searXNG（自托管搜索聚合引擎）**
- 开源隐私搜索引擎，同时查询Google/Bing/DuckDuckGo/Baidu等多个引擎
- 完全自托管，不需要任何API Key
- Docker一键部署：`docker run -d -p 8888:8080 searxng/searxng`
- 适合Mac Mini常驻
- 缺点：国内访问Google可能需要代理
- 适合场景：想要独立干净搜索界面、不被追踪、不依赖任何服务商API

**与RSS源的关系**：
- GI Skill之前用的BBC/CNN/Reuters/Guardian RSS源已被墙（4/29用户了解）
- ProSearch可以替代RSS做情报采集，走的是搜索聚合而非订阅拉取
- 方案B可以彻底解决数据源问题

**当前状态**：用户听了方案B介绍，未表态，等Mac Mini到位再考虑部署
