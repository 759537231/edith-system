# 术数入门指南

## 核心认知

> "我是不是只要能得到卦象，我就可以卜，甚至不需要？"
> "对，核心是解卦，不是起卦。"

**万物皆可起卦**，起卦方法只是得到卦象的手段。心诚则灵，随机即天意。

## 术数分类

| 类别 | 术数 | 看什么 | 用途 |
|------|------|--------|------|
| 命 | 紫微斗数、八字、铁板神数 | 一生 | 命运分析 |
| 卜 | 奇门遁甲、六爻、梅花易数、测字 | 当下 | 预测决策 |
| 相 | 风水、面相、手相 | 空间/人 | 环境/识人 |
| 时 | 太乙神数、大六壬 | 天时/人事 | 国运/大事 |

## 六爻金钱课

用三枚铜钱（硬币）抛掷六次起卦：

### 爻的记录

| 铜钱结果 | 名称 | 记录 | 是否变爻 |
|---------|------|------|---------|
| 三个正面 | 老阳 | ○ | 是 |
| 三个反面 | 老阴 | × | 是 |
| 两正一反 | 少阳 | — | 否 |
| 两反一正 | 少阴 | - - | 否 |

### 步骤

1. 准备三枚铜钱（或硬币）
2. 默念心中所问之事
3. 将三枚铜钱抛掷六次
4. 从下往上记录六个爻
5. 下三爻=下卦（内卦），上三爻=上卦（外卦）
6. 上下卦组合成64卦中的一个

## 梅花易数

宋代邵雍（邵康节）创立，万物皆可起卦。

### 起卦方法

1. **时间起卦**：年月日时→数字→卦象
2. **数字起卦**：报数/手机号/车牌号→卦象
3. **文字起卦**：姓名笔画/问题字数→卦象
4. **声音起卦**：说话声/鸟叫→卦象
5. **物体起卦**：树叶/石头/硬币→卦象
6. **方位起卦**：面朝方向→卦象
7. **直觉起卦**：心里随便想一个卦名

### 最简方法

- **报数法**：心里想一个数字（1-64）→对应卦象
- **看时钟法**：看一眼时钟（10:30）→10+30=40→对应卦象
- **随便想法**：心里随便想一个卦名→就是你的卦象

## 解卦核心

1. **看本卦**：当前情况（卦辞+爻辞）
2. **看变卦**：未来变化（卦辞+爻辞）
3. **看互卦**：中间过程
4. **综合分析**：得出结论

## 需要背的基础

### 八卦口诀

```
乾三连 ☰  三横连在一起
坤六断 ☷  三横断成六段
震仰盂 ☳  像一个仰着的碗
艮覆碗 ☶  像一个扣着的碗
离中虚 ☲  中间是空的
坎中满 ☵  中间是满的
兑上缺 ☱  上面缺一口
巽下断 ☴  下面断一截
```

|----|------|------|------|------|

| 坤 | 地 | 西南 | 土 | 母 |
| 震 | 雷 | 东 | 木 | 长男 |

| 兑 | 泽 | 西 | 金 | 少女 |

### 五行生克

**相生**：木→火→土→金→水→木
**相克**：木→土→水→火→金→木

### 天干地支

**十天干**：甲乙丙丁戊己庚辛壬癸
**十二地支**：子丑寅卯辰巳午未申酉戌亥

## 学习路径建议

1. **八卦口诀+五行生克**：最基础，必须背
2. **梅花易数**：最简单，随时能用
3. **六爻金钱课**：比较系统，需要起卦
4. **奇门遁甲**：比较复杂，需要排盘
5. **紫微斗数**：需要排盘，比较直观
