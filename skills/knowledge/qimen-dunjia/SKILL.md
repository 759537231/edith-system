## 断事方法

**找东西/找人：** 看生门落哪个宫 → 那个方向能找到

**⚠️ 核心流程（必须遵守）：**
1. 站定不动，面朝一个方向
2. 起局/看八门方位
3. 往吉门方向走
4. 找到找不到 = 验证

**❌ 绝对不能做的事：** 先找到人，再问"她在哪个门"——这叫事后验证，不是奇门指引。奇门的价值是"先告诉你往哪走"，不是"事后解释她为什么在那"。

**找人具体方法：**

*简易版（不用排盘）：*
1. 站定，面朝一个方向
2. 八门方位自动确定（面朝=景门，身后=休门，左前=生门，右前=开门，左后=伤门，右后=杜门，左=惊门，右=死门）
3. 优先往吉门方向走：身后（休门）、左前（生门）、右前（开门）
4. 找不到就换下一个吉门方向

*进阶版（用神法，需排盘）：*
1. 根据当前时间起奇门局
2. 确定用神——找什么人对应什么符号：
   - 媳妇/妻子 → 六合（代表婚姻、结合）
   - 孩子 → 天辅（代表教育、辅佐）
   - 老人 → 天芮（代表长辈、坤）
   - 朋友 → 太阴（代表隐秘、暗中）
3. 看用神落在哪个宫，那个宫的方位就是目标所在

**测吉凶：** 看方位的门
- 吉门（开休生）→ 有利
- 凶门（死惊伤）→ 不利
- 中平（杜景）→ 看情况

**五行生克：**
- 相生 → 吉
- 相克 → 凶
- 比和 → 平

## 科学vs玄学vs迷信

用户问"奇门遁甲到底是科学、玄学还是迷信"，回答框架：

- **说它科学** — 不对。没有可重复实验，没有物理机制解释
- **说它迷信** — 也简单了。有完整理论体系（阴阳五行、天干地支），不是胡编的
- **说它玄学** — 比较准确。是中国古代的一套符号系统和解释框架

**关键在心态：**
- 当参考、当启发、当思考框架 → 没问题
- 当绝对真理、当决策唯一依据 → 那就是迷信

**类比：** 天气预报说"明天有雨"，你带把伞，没下雨也不亏。这不叫迷信，叫多一个参考。

## 验证问题（用户指出的逻辑死结）

用户指出奇门遁甲的根本验证问题：
- 先预测再找 → 找到了算准，找不到算不准
- 先找到再问 → 事后对号入座，不算验证

**结论：** 奇门遁甲没法像科学实验那样"可重复验证"。

**换个角度：** 奇门的价值可能不在于"预测准不准"，而在于"给你一个方向"。它只是帮你做了一个随机选择，省得你站在原地纠结。本质上，它是一个"决策辅助工具"，不是"预测机器"。

### 八门吉凶的含义

**为什么休门是吉门？**
- "休"= 休息、安逸、养精蓄锐
- 古代兵法"以逸待劳"——你休息好了，精力充沛，对手跑累了
- 休门代表：安静、稳定、不急不躁、有余裕
- 在找人场景中，人在休门方位 = 她在安稳状态，没乱跑

**八门吉凶速记：**
- 大吉：开门（通达）、休门（安逸）、生门（希望）
- 凶：伤门（损害）、死门（终结）、惊门（惊恐）
- 中平：杜门（隐藏）、景门（光明）

**Q: 为什么"前"是离？**
A: 约定俗成。古人面南而立，南=离，所以前=离。这是规矩，没有为什么。

用户对三易有深入兴趣，已完成64卦反推和三才易系统构建。用户命名"三才易"（天、地、人三才合一）。

### ⚠️ 三才易核心顺序（用户多次纠正，最终定稿）

**顺序：归藏易→连山易→周易**

用户的原话（2026-05-06）：
> "归藏易的归藏也不是安定回归之意，而是厚积薄发之意，意为蛰服埋藏积淀，遂为之头。大地为始包容万物，生之为群山，连绵不绝，此为连山。山有万象，生而为命，山自岿然不动，擎天之天之山，命自归天，天人合一也，此为周天，遂为周易。"

**三才对应：**

| 顺序 | 易书 | 核心 | 象征 | 含义 |
|------|------|------|------|------|
| 第一 | 归藏易 | 藏 | 大地 | 蛰伏、埋藏、积淀、厚积薄发。大地为始，包容万物 |
| 第二 | 连山易 | 连 | 群山 | 群山连绵不绝，山有万象，生而为命 |
| 第三 | 周易 | 周 | 天 | 命自归天，天人合一，周天运转 |

**核心循环：藏→连→周（大地→群山→天）**

**应用框架：谋→动→定**
- 第一步：谋（归藏易·藏）— 蛰伏、埋藏、积淀，厚积薄发，大地为始
- 第二步：动（连山易·连）— 群山万象，生而为命，连绵不绝
- 第三步：定（周易·周）— 命自归天，天人合一，周天运转
- 循环：谋→动→定→谋（周而复始）

**应用：**
- 困境：先谋后动，动后定
- 成功：谋中有动，动后定
- 决策：谋动结合，定而后谋

### 用户纠正过程（重要教训）

1. 我最初说"动→止→藏" → 用户说"应该是止动藏"
2. 我改成"止→动→藏" → 用户说"谋而后动，动而后定"
3. 我改成"谋→动→定" → 用户确认
4. 我把归藏易写成"安定回归" → 用户纠正"不是安定回归，是厚积薄发"
5. 我把连山易和归藏易的卦辞象辞照抄周易改几个字 → 用户说"不要偷懒，好好搞"
6. 最终每卦的归藏易/连山易都有独特含义，体现各自核心思想

**教训：**
- 归藏易 ≠ "安定回归"，= "蛰伏、埋藏、积淀、厚积薄发"
- 连山易 ≠ "群山归一"，= "群山万象，生而为命，连绵不绝"
- 周易 ≠ "变化行动"，= "命自归天，天人合一，周天运转"
- 不能照抄周易改几个字当归藏/连山的卦辞，每卦要有独特含义

### 关键发现

- 王家台秦简《归藏》（1993年出土）证明归藏易确实存在
- 归藏卦名与周易不同：坤→"藏"，乾→"天"
- 周易用九"群龙无首"可能源于连山易"止"的思想
- 周易用六"利永贞"可能源于归藏易"藏"的思想

- 能确定：首卦、核心思想
- 能推断：卦序方向、思想框架
- 无法确定：卦名、卦辞、具体内容（连山易完全失传，归藏易部分出土）
