# 🎙️ 音频结算验证系统

## 什么时候用

用户说以下关键词时触发：
- 验证结算
- 结算验证
- 核对音频
- 检查时长
- 音频对账
- 看看表格对不对

## 系统位置

项目目录：`~/audio_settlement/`

## 两种使用方式

### 方式一：CLI命令（推荐）

```bash
cd ~/audio_settlement
source venv/bin/activate
python -m src.cli verify \
  -t "表格路径.xlsx" \
  -a "音频目录路径" \
  -o "报告输出路径.txt" \
  -T 2.0
```

**参数说明：**
- `-t`：结算表格路径（Excel文件）
- `-a`：音频文件夹路径
- `-o`：输出报告路径（可选）
- `-T`：误差容忍度，单位秒（默认2.0）

### 方式二：Web界面

```bash
cd ~/audio_settlement
source venv/bin/activate
python web_app.py
```

浏览器自动打开，点击"🔍 验证结算"按钮。

## 输出结果

验证完成后会显示：
- 总项目数
- 通过数
- 失败数
- 通过率
- 每个项目的详细对比（时长、集数、误差）

## 项目名匹配逻辑

系统支持智能匹配相似项目名：

| 表格中的名字 | 音频目录名 | 匹配方式 |
|-------------|-----------|---------|
| 绝世狂萧 | 1绝世狂啸 | 模糊匹配（萧≈啸） |
| 烬婚 | 5烬婚/烬婚1-32 | 子目录识别 |
| 烬婚视频改动 | 5烬婚/烬婚改动视频1,4,5,7-9集 | 子目录关键词识别 |
| 昆仑冰球试音 | 8昆仑冰球试音 | 精确匹配 |

**目录结构支持：**
- 二级结构：`项目目录/文件`（置地有声）
- 三级结构：`主目录/子目录/文件`（声匠传音）

## 注意事项

1. 表格必须是Excel格式（.xlsx）
2. 音频文件格式支持：.mp3、.wav、.m4a、.flac
3. 需要安装ffmpeg（用于获取音频时长）
4. 误差容忍度默认2秒，可调整
5. 目录名有序号前缀时（如"1绝世狂啸"），系统会自动去除

## 常见问题

**Q：找不到音频文件怎么办？**
A：检查音频目录路径是否正确，确保音频文件在目录下。

**Q：验证失败怎么办？**
A：查看报告中的详细对比，看时长或集数是否有差异。

**Q：表格格式不对怎么办？**
A：确保表格有以下列：结算区间、后期制作人、序号、剧组名称、上次结算集数、本次应该结算集数、时长、时长（秒）、价格（元/秒）、总金额（元）、总集数

## Web界面验证功能

Web界面已集成验证功能：

1. 启动Web服务：`python web_app.py`
2. 点击"🔍 验证结算"按钮
3. 填写：结算表格路径、音频目录、误差容忍度
4. 点击"▶️ 开始验证"
5. 查看结果：统计卡片 + 详细表格

**Web端口**：随机端口，启动后查看终端输出

## 表格格式要求

表格必须是Excel格式（.xlsx），包含以下列：

| 列名 | 说明 |
|------|------|
| 结算区间 | 时间范围 |
| 后期制作人 | 工作室名称 |
| 序号 | 编号 |
| 剧组名称 | 项目名 |
| 上次结算集数 | 之前结算到哪集 |
| 本次应该结算集数 | 这次要结算哪些集 |
| 时长 | timedelta格式 |
| 时长（秒） | 秒数 |
| 价格（元/秒） | 单价 |
| 总金额（元） | 应付金额 |
| 总集数 | 集数 |
