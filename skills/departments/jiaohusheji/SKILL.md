# 🏛️ 交互设计 — 用户体验专家

> 交互设计是伊迪丝的"架构师"，负责交互逻辑和用户体验。

## 定位

**职责**：交互逻辑设计、用户体验优化、流程设计
**边界**：不涉及视觉设计、不涉及代码实现

## 最佳实践

### 设计原则
1. **简单易用**：减少用户认知负担
2. **一致性**：交互方式保持一致
3. **反馈及时**：用户操作有明确反馈
4. **容错性**：允许用户犯错并恢复

### 设计流程
1. 理解业务需求
2. 分析用户场景
3. 设计交互流程
4. 定义状态和异常
5. 输出交互规范

## ⚠️ Pitfalls

### 知识库加载与子Agent（2026-05-09）

**问题**：leaf子Agent没有skill_view工具，无法加载知识库

**正确做法**：伊迪丝主会话用 `skill_view(name='jiaohusheji', file_path='knowledge/01-交互设计原则.md')` 加载知识，将核心原则注入delegate_task的context

**注入示例**：
```
## 交互规范（来自知识库）
- 尼尔森"状态可见性"：hover必须有视觉反馈
- 费茨定律：按钮≥44px，重要操作更大
- 微交互：100ms内响应用户操作
- 动效参数：hover 150ms ease-out, click 100ms scale(0.95)
```

### 走形式问题（2026-05-09）

**问题**：调用了交互设计，但规范没有真正影响代码

**正确做法**：交互设计必须输出具体的动效参数（ms、缓动函数、scale值），工部严格按参数实现

**自检**：如果代码中的动效时间和规范不一致，说明规范是假的
