# 影视构图原则

## 一、基础构图法则

### 三分法
```
┌───┬───┬───┐
│   │   │   │
├───┼───┼───┤
│   │ ● │   │  ← 主体放在交叉点
├───┼───┼───┤
│   │   │   │
└───┴───┴───┘
```
- 将画面分成3×3的九宫格
- 主体放在交叉点或线上
- 比居中更有动感和美感

### 黄金比例
- 比例约为1:1.618
- 比三分法更精确
- 自然界中常见的美感比例

### 黄金螺旋
```
    ┌──────────────┐
    │    ┌────────┐│
    │    │  ┌─────┐│
    │    │  │  ◎  ││
    │    │  └─────┘│
    │    └────────┘│
    └──────────────┘
```
- 视觉焦点在螺旋中心
- 引导观众视线移动
- 适合风景、建筑摄影

## 二、引导线构图

### 引导线类型
| 类型 | 描述 | 案例 |
|------|------|------|
| 直线引导 | 道路、栏杆、河流 | 公路片 |
| 曲线引导 | 小路、河流、海岸线 | 风光摄影 |
| 对角线 | 楼梯、斜坡 | 动感画面 |
| 汇聚线 | 铁轨、走廊 | 纵深感 |

### 引导线作用
- 引导观众视线到主体
- 制造纵深感和空间感
- 增加画面的动感

## 三、对称构图

### 对称类型
| 类型 | 描述 | 适用 |
|------|------|------|
| 左右对称 | 画面左右镜像 | 建筑、倒影 |
| 上下对称 | 画面上下镜像 | 水面倒影 |
| 辐射对称 | 从中心向外扩散 | 花朵、穹顶 |

### 对称效果
- 庄重、稳定、和谐
- 适合仪式感、正式场合
- 韦斯·安德森电影标志

## 四、框架构图

### 框架元素
- 门框、窗框
- 树枝、拱门
- 隧道、走廊

### 框架作用
- 增加层次感
- 聚焦观众注意力
- 制造窥视感

## 五、景别与构图

### 远景构图
- 展示环境全貌
- 人物占画面比例小
- 强调氛围和空间感

### 中景构图
- 展示人物半身
- 适合对话和动作
- 注意人物视线方向

### 特写构图
- 展示细节和情绪
- 背景虚化，突出主体
- 注意眼睛位置（三分线上方）

## 六、画面平衡

### 平衡方式
| 方式 | 描述 | 效果 |
|------|------|------|
| 对称平衡 | 左右相同重量 | 稳定、庄重 |
| 非对称平衡 | 不同元素平衡 | 生动、有趣 |
| 色彩平衡 | 冷暖色平衡 | 视觉舒适 |
| 明暗平衡 | 光影平衡 | 层次丰富 |

### 失衡效果
- 可以故意制造失衡
- 表达不安、紧张、冲突
- 用于心理描写

## 七、负空间

### 负空间定义
- 主体之外的空间
- 留白、空白区域

### 负空间作用
- 突出主体
- 制造孤独感、空旷感
- 给观众想象空间

### 负空间案例
- 大海中的一艘小船
- 空旷街道上的一个人
- 纯色背景前的主体

## 八、色彩构图

### 色彩对比
- 互补色对比（红-绿、蓝-橙）
- 冷暖色对比
- 明暗对比

### 色彩引导
- 用色彩引导视线
- 高饱和度吸引注意力
- 低饱和度作为背景

## 九、动态构图

### 动态构图原则
- 为运动留出空间
- 运动方向前方留白
- 预判运动轨迹

### 运动模糊
- 适当运动模糊增加动感
- 主体清晰，背景模糊
- 追焦拍摄

## 十、竖屏构图技巧

### 竖屏特点
- 9:16比例
- 上下空间大
- 适合人物、产品

### 竖屏构图要点
- **主体居中**：核心区域在中间1/3
- **上下分区**：上放标题，下放CTA
- **近景为主**：竖屏适合近景和特写
- **大元素**：手机屏幕小，元素要大

### 竖屏禁忌
- 不要放太多元素
- 不要文字太小
- 不要主体太远
