# 脚本写作方法论

## 一、故事结构

### 三幕式结构
| 幕 | 占比 | 内容 | 关键点 |
|---|------|------|--------|
| 第一幕：建置 | 25% | 介绍人物、世界、冲突 | 钩子、触发事件 |
| 第二幕：对抗 | 50% | 冲突升级、主角挣扎 | 障碍、反转、高潮 |
| 第三幕：解决 | 25% | 冲突解决、结局 | 最终对决、收尾 |

### 英雄之旅（12步）
1. **平凡世界**：主角的日常生活
2. **冒险召唤**：出现问题/机会
3. **拒绝召唤**：主角犹豫
4. **遇见导师**：获得指引
5. **跨越门槛**：进入新世界
6. **考验、盟友、敌人**：遇到挑战
7. **接近最深的洞穴**：准备面对核心冲突
8. **磨难**：最大的挑战
9. **奖赏**：获得能力/宝物
10. **返回之路**：踏上归途
11. **复活**：最终考验
12. **带着万灵药归来**：回到平凡世界，但已改变

### 起承转合（东方结构）
| 阶段 | 作用 | 技巧 |
|------|------|------|
| 起 | 开头，引入 | 钩子，3秒抓住注意力 |
| 承 | 发展，铺垫 | 层层递进，保持兴趣 |
| 转 | 转折，冲突 | 意外，反转，高潮 |
| 合 | 结尾，收束 | 升华，呼应开头 |

### 短视频结构（30秒-3分钟）
```
0-3秒：钩子（Hook）— 抛出问题/冲突/悬念
3-15秒：背景 — 快速交代 context
15-60秒：核心 — 主要内容/冲突/高潮
最后5秒：结尾 — CTA/反转/金句
```

## 二、剧本格式

### 标准剧本格式
```
场景1：室内 - 咖啡厅 - 白天

[画面] 一个年轻人坐在窗边，手握咖啡杯，望着窗外
[音乐] 轻柔的钢琴曲

李明
（自言自语）
又是普通的一天...

[画面切换] 手机屏幕亮起，显示一条消息
[音效] 消息提示音

李明
（惊讶）
什么？！
```

### 短视频脚本模板
| 列 | 内容 |
|---|------|
| 时长 | 0:00-0:03 |
| 画面 | 镜头描述 |
| 文案 | 旁白/字幕 |
| 音乐 | 背景音乐/音效 |
| 备注 | 特殊要求 |

## 三、对白技巧

### 对白原则
1. **推动剧情**：每句对白都要有目的
2. **揭示人物**：通过对白展示性格
3. **潜台词**：说的和想的不一样
4. **简洁有力**：少用形容词，多用动词

### 对白节奏
- 紧张场景：短句、快节奏
- 抒情场景：长句、慢节奏
- 冲突场景：打断、抢话、沉默

### 旁白技巧
- **第一人称**：亲切、代入感强
- **第三人称**：客观、全知视角
- **内心独白**：揭示心理活动
- **金句收尾**：升华主题

## 四、节奏把控

### 节奏类型
| 类型 | 特点 | 适用 |
|------|------|------|
| 快节奏 | 短镜头、快剪、多动作 | 动作片、广告 |
| 慢节奏 | 长镜头、慢剪、少动作 | 文艺片、纪录片 |
| 变节奏 | 快慢交替 | 大多数视频 |

### 节奏控制技巧
1. **镜头时长**：快=1-2秒，慢=3-5秒
2. **剪辑频率**：快剪=密集切换，慢剪=长镜头
3. **音乐节拍**：卡点剪辑，配合音乐节奏
4. **情绪曲线**：有起伏，有高潮

## 五、冲突设计

### 冲突类型
| 类型 | 描述 | 案例 |
|------|------|------|
| 人vs人 | 角色之间的对立 | 谍战片 |
| 人vs自然 | 与自然环境的对抗 | 荒野求生 |
| 人vs自我 | 内心的挣扎 | 心理剧 |
| 人vs社会 | 与体制/规则的冲突 | 职场剧 |
| 人vs命运 | 与命运的抗争 | 悲剧 |

### 冲突升级技巧
1. **层层递进**：从小冲突到大冲突
2. **反转**：出乎意料的转折
3. **两难选择**：没有完美解决方案
4. **时间压力**：倒计时增加紧迫感

## 六、角色塑造

### 角色要素
| 要素 | 描述 |
|------|------|
| 目标 | 角色想要什么 |
| 动机 | 为什么想要 |
| 障碍 | 什么阻止他 |
| 弱点 | 人性的弱点 |
| 成长 | 如何改变 |

### 角色类型
- **主角**：推动故事，有成长弧线
- **对手**：制造冲突，不是单纯的坏人
- **导师**：提供指引，关键时刻出现
- **盟友**：支持主角，增加人情味

## 七、开头钩子设计

### 钩子类型
| 类型 | 技巧 | 案例 |
|------|------|------|
| 悬念 | 抛出问题 | "你知道吗？90%的人都做错了" |
| 冲突 | 展示矛盾 | 两人争吵画面 |
| 反常 | 打破常规 | 意外的画面/行为 |
| 利益 | 直接利益 | "教你一招省1000块" |
| 情感 | 引发共鸣 | "你有没有过这样的时刻..." |

### 3秒法则
- 前3秒决定用户是否继续看
- 必须在3秒内抓住注意力
- 不要从自我介绍开始

## 八、结尾设计

### 结尾类型
| 类型 | 效果 | 适用 |
|------|------|------|
| 开放式 | 引发思考 | 文艺片 |
| 封闭式 | 给出答案 | 故事片 |
| 反转式 | 意外结局 | 悬疑片 |
| 升华式 | 提升主题 | 纪录片 |
| CTA式 | 引导行动 | 短视频 |

### 金句收尾
- 总结主题
- 引发共鸣
- 留下记忆点
- 简洁有力
