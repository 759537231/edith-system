## 知识库位置

```
~/.hermes/skills/departments/{部门名}/knowledge/
```

## 子Agent限制

子Agent（通过delegate_task调用）没有skill_view工具：
- 不能自己加载SKILL.md
- 不能自己读取知识库
- 需要伊迪丝在context中注入所需信息

## 正确调用流程

```python
# 1. 伊迪丝加载知识库
skill_view(name='meishusheji', file_path='knowledge/01-色彩理论.md')

# 2. 提取核心内容
core_content = "色彩理论核心：..."

# 3. 注入到delegate_task
delegate_task(
    goal="出设计规范",
    context=f"参考知识库：\n{core_content}\n\n按规范输出。"
)
```

## 用户理解的架构

```
用户 → 伊迪丝（理解+调度+把关）→ 各部门（执行）
```

- 伊迪丝是大脑，部门是手脚
- 伊迪丝负责"做什么"，各部门负责"怎么做"
- 用户只和伊迪丝对话，不需要直接指挥各部门

## 同步机制

部门之间不直接通信，都通过伊迪丝传递：

```
美术设计 → 规范 → 伊迪丝 → 汇总 → 工部
交互设计 → 规范 → 伊迪丝 ↗
```

伊迪丝是翻译官，把各部门的输出翻译成下一步的输入。
