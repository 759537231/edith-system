# 音频结算验证 — Excel格式说明

## 声匠传音格式

**文件名示例：** 《声匠传音》5月5日漫剧后期MIX时长.xlsx

**列结构（A-K）：**
| 列 | 内容 | 类型 |
|----|------|------|
| A | 结算区间 | 文本（如"2026.4.5-2026.5.5"） |
| B | 后期制作人 | 文本（如"声匠传音"） |
| C | 序号 | 数字 |
| D | 剧组名称 | 文本 |
| E | 上次结算集数 | 文本或空 |
| F | 本次应该结算集数 | 文本（如"75-93"或"1-32"） |
| G | 时长 | timedelta格式 |
| H | 时长（秒） | 浮点数 |
| I | 价格（元/秒） | 浮点数或文本（如"300元/条"） |
| J | 总金额（元） | 浮点数 |
| K | 总集数 | 整数 |

**特点：**
- 单价：0.33元/秒 或 0.67元/秒
- 目录结构：有子目录，如"1绝世狂啸/绝世狂萧第89集MIX.mp3"
- 项目名可能与目录名不同（如"绝世狂萧" vs "1绝世狂啸"）

## 置地有声格式

**文件名示例：** 【置地有声后期工作室】【2026年5月】结算工作.xlsx

**列结构：** 同声匠传音

**特点：**
- 单价：0.33元/秒、0.5元/秒、或按条计费（如"300元/条"）
- 目录结构：无子目录，音频文件直接在目录下
- 项目名从文件名提取（如"重生第21集aMIX.mp3" → 项目名"重生"）
- 有"a""b"集的情况（如"21a""21b"）

## 匹配逻辑详解

### 目录结构差异

**声匠传音：**
```
《声匠传音》5月5日漫剧后期MIX时长/
├── 1绝世狂啸/
│   ├── 绝世狂萧第75集 MIX.mp3
│   ├── 绝世狂萧第76集MIX.mp3
│   └── ...
├── 2末世首富/
│   └── 末世首富第52集MIX.mp3
├── 3深海/
│   └── ...
└── 4炸鸡/
    └── ...
```

**置地有声：**
```
【置地有声后期工作室】【2026年5月】MIX/
├── 重生第21集aMIX.mp3
├── 重生第21集bMIX.mp3
├── 重生第22集MIX.mp3
├── 机甲预告片MIX.wav
├── 人在异世第10集MIX.mp3
└── ...
```

### 项目名匹配规则

1. **精确匹配**：表格项目名 == 目录名
2. **去掉序号前缀**："1绝世狂啸" → "绝世狂啸"
3. **模糊匹配**：
   - 双向包含匹配
   - 最后一个字不同但其他相同（如"萧"和"啸"）
   - 去掉常见后缀后匹配（试音、视频改动、预告片）
4. **特殊处理**：
   - 试音项目优先匹配试音目录
   - 视频改动项目匹配对应目录
5. **避免重复匹配**：一个音频目录只能匹配一个表格项目

### 文件名解析

**声匠传音：**
- 文件名格式：`{剧名}第{集数}集MIX.mp3`
- 示例：`绝世狂萧第89集MIX.mp3`
- 提取：项目名=绝世狂萧，集数=89

**置地有声：**
- 文件名格式：`{剧名}第{集数}集MIX.mp3` 或 `{剧名}第{集数}{a/b}MIX.mp3`
- 示例：`重生第21集aMIX.mp3`
- 提取：项目名=重生，集数=21a
