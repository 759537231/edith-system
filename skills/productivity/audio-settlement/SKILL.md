# 音频结算验证系统

## 项目位置

`~/audio_settlement/`

## 核心功能

验证后期工作室提交的结算表（Excel）与实际音频文件是否一致：
- 时长是否匹配
- 集数是否匹配
- 生成验证报告

## 使用方法

```bash
cd ~/audio_settlement

# 验证结算
python -m src.cli verify \
  -t "表格路径.xlsx" \
  -a "音频目录" \
  -o "报告输出路径.txt"

# 参数说明
# -t: Excel表格路径
# -a: 音频文件目录
# -o: 验证报告输出路径（可选）
# -T: 误差容忍度秒数（默认2.0）
```

## Excel格式

详见 `references/audio-settlement-verification.md`

**声匠传音格式：**
- 列：结算区间/后期制作人/序号/剧组名称/上次结算集数/本次结算集数/时长/时长(秒)/价格/总金额/总集数
- 单价：0.33元/秒 或 0.67元/秒
- 目录结构：有子目录（如"1绝世狂啸/"）

**置地有声格式：**
- 列结构同上
- 单价：0.33元/秒、0.5元/秒、或按条计费
- 目录结构：无子目录，音频文件直接在目录下

## 匹配逻辑

项目名匹配规则（按优先级）：
1. 精确匹配
2. 去掉序号前缀后匹配（"1绝世狂啸" → "绝世狂啸"）
3. 模糊匹配（支持同音字如"萧"和"啸"，使用SequenceMatcher计算相似度）
4. 试音项目优先匹配试音目录
5. 避免重复匹配（一个音频目录只能匹配一个表格项目）

### 三级目录结构支持

声匠传音的部分项目有三级目录结构（如烬婚）：
```
5烬婚/
├── 烬婚1-32/           ← 原版32集
│   └── 烬婚第10集 MIX.mp3
└── 烬婚改动视频1,4,5,7-9集/  ← 改动版6集
    └── 烬婚第1集MIX.mp3
```

匹配时根据子目录名判断：
- 含"改动"或"视频" → 匹配为"{项目名}视频改动"
- 含"试音" → 匹配为"{项目名}试音"
- 其他 → 匹配为原版项目名
