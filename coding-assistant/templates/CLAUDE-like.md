## Git规范

### 分支命名
- **功能分支**：`feature/{功能名}`
- **修复分支**：`fix/{问题描述}`
- **发布分支**：`release/{版本号}`

### 提交信息
```
{类型}({范围}): {描述}

{详细说明}

{关联Issue}
```

**类型**：
- `feat`：新功能
- `fix`：修复Bug
- `docs`：文档更新
- `style`：代码格式调整
- `refactor`：重构
- `test`：测试相关
- `chore`：构建/工具相关
